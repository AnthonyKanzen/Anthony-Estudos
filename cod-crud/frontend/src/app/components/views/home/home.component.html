Sistema de Cadastro de Produtos

Este projeto foi desenvolvido durante meus estudos de Angular, com o objetivo de praticar a construção de uma aplicação web utilizando CRUD (Create, Read, Update e Delete).

Tecnologias utilizadas

  • Angular: construção do frontend
  • TypeScript: desenvolvimento da aplicação
  • Angular Material: criação e estilização da interface
  • RxJS: gerenciamento de dados e operações assíncronas
  • HttpClient: comunicação com a API
  • JSON Server: simulação do backend
  • HTML e CSS: estrutura e estilização das páginas

O que foi desenvolvido

O projeto possui funcionalidades para cadastrar, listar, consultar, editar e excluir produtos, além da utilização de services, componentes, rotas, interfaces, modelos e formulários.

O objetivo foi relembrar e reforçar alguns conceitos de Angular, compreender na prática como uma aplicação é estruturada e como o frontend pode se comunicar com uma API.
