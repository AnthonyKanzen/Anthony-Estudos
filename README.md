## 📖 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de Angular, com o objetivo de relembrar e reforçar conceitos fundamentais do framework e colocar em prática a construção de uma aplicação web utilizando as operações de CRUD (Create, Read, Update e Delete).

A aplicação consiste em um sistema de cadastro e gerenciamento de produtos, permitindo realizar operações como adicionar, visualizar, editar e excluir produtos.

Além do desenvolvimento do frontend com Angular, também foi criado um backend simples utilizando JSON Server, responsável por simular uma API REST e armazenar os dados dos produtos em um arquivo JSON. Dessa forma, a aplicação consegue realizar requisições HTTP para consultar e manipular os dados, proporcionando uma experiência mais próxima de uma aplicação completa com frontend e backend.

O projeto também foi utilizado para praticar conceitos como componentes, serviços, rotas, formulários, requisições HTTP, comunicação com API e organização de uma aplicação Angular.

## 🛠️ Tecnologias utilizadas
- Angular
- TypeScript
- Angular Material
- RxJS
- HttpClient
- HTML
- CSS
- JSON Server
